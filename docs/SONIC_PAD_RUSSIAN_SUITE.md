# Комплексная русификация Sonic Pad 54.20

Один пакет объединяет русский интерфейс сенсорного экрана Sonic Pad, исправления переносов русских подписей и включение русского языка в браузерном Fluidd. Перевод экрана взят с работающего Sonic Pad владельца проекта. Пакет не устанавливает службу Falcon A1: она распространяется отдельно.

**Совместимость:** Creality Sonic Pad V1.0.6.54.20, экранная оболочка fluidd-pad V1.3.3 от 2023/10/10, веб-интерфейс V1.0.18_fluidd на базе Fluidd 1.24.0. Установщик проверяет контрольные суммы ресурсов; для другой сборки установка остановится. Требуются root-доступ по SSH и Python 3.7 или новее на Pad.

## Скачать

[Общий релиз](https://github.com/arandit21/Falcon-Design-Space-Sonic-Pad/releases/tag/sonic-pad-russian-54.20-v1.0.0)

- `Sonic_Pad_Russian_54.20_1.0.0.tar.gz` — готовый пакет для установки на Pad.
- `Sonic_Pad_Russian_54.20_1.0.0_sources.tar.gz` — исходники установщика, словарь и необходимые исходные ресурсы для повторной сборки.
- `SHA256SUMS.txt` — контрольные суммы файлов релиза.

Это предварительный выпуск нового общего установщика. Содержимое перевода используется на рабочем Pad; установка и откат общего пакета проверены на локальной копии файлов. Новый установщик на устройстве не запускался.

## Что входит

Заменяются только 13 статических файлов: три JS-файла экрана, семь CSS-файлов экрана и три файла браузерного Fluidd. Русский словарь содержит 1474 строковых значения в 28 группах. Для экрана соглашения о конфиденциальности при русском языке используется английский текст: полностью русскими все ресурсы оболочки не объявляются.

Конфигурации принтера, MCU, сеть, пароли, SSH-ключи, настройки пользователя, службы управления и камера не входят в пакет и не изменяются. Qt-загрузчик `main.qml` только проверяется. Установка не отправляет команды принтеру, не запускает печать и не перезапускает службы или устройство автоматически.

Семь CSS-файлов заменяются после проверки базовой сборки оболочки. Если в них были свои изменения, установщик сохранит их в резервной копии. Известные исходные файлы и предыдущие опубликованные версии патча Fluidd поддерживаются; неизвестные изменения основных JS-файлов требуют отдельной проверки.

## Установка

Завершите текущую печать и другие работы с устройством. Скачайте готовый архив на Windows. В PowerShell перейдите в папку загрузки и отправьте его на Pad. Вместо `192.168.1.36` укажите IP своего Sonic Pad:

```powershell
scp -O -oHostKeyAlgorithms=+ssh-rsa -oPubkeyAcceptedAlgorithms=+ssh-rsa -oMACs=+hmac-sha1 .\Sonic_Pad_Russian_54.20_1.0.0.tar.gz root@192.168.1.36:/mnt/UDISK/
ssh -oHostKeyAlgorithms=+ssh-rsa -oPubkeyAcceptedAlgorithms=+ssh-rsa -oMACs=+hmac-sha1 root@192.168.1.36
```

Введите пароль root своего Pad. После входа выполните команды по очереди:

```sh
cd /mnt/UDISK
tar -xzf Sonic_Pad_Russian_54.20_1.0.0.tar.gz
cd Sonic_Pad_Russian_54.20_1.0.0
sh install.sh check
sh install.sh install
sh install.sh verify
```

`check` проверяет совместимость и содержимое пакета, не меняя файлов устройства. При ошибке проверки не продолжайте установку. Успешные результаты: `CHECK PASSED`, затем `INSTALLED` и `VERIFIED`. Если все файлы уже совпадают, установка сообщит `ALREADY INSTALLED`.

После установки выберите русский язык в настройках языка экрана. Если список ещё старый, после завершения работ штатно перезагрузите Pad. В браузерном Fluidd обновите страницу без кэша, при необходимости очистите данные сайта, затем выберите «Русский» в настройках интерфейса. Язык автоматически не переключается, чтобы сохранить пользовательские настройки.

Отдельные старые архивы Fluidd и WRAP FIX поверх общего пакета устанавливать не нужно.

## Резервная копия и возврат

Перед первой фактической заменой сохраняются исходные 13 файлов:

```text
/mnt/UDISK/sonic-pad-russian-54.20-backup/original/
```

Эта копия не перезаписывается при повторной установке. Для каждой попытки также создаётся отдельная копия состояния до изменений. При ошибке копирования установщик пытается вернуть состояние перед этой попыткой; при проблемах с диском сохраняйте журнал и резервные копии.

Чтобы вернуть состояние до первой установки общего пакета, из его папки выполните:

```sh
sh install.sh restore
```

Возврат восстанавливает именно сохранённые файлы, а не гарантированно заводскую прошивку. Если до общего пакета уже были установлены отдельные русификаторы, они останутся в исходной копии. Если пакет сообщил `ALREADY INSTALLED`, он ничего не менял и новую исходную копию не создавал. После обновления прошивки старый откат использовать нельзя: проверка совместимости остановит его.

## Проверки и сборка

Установщик проверен локально: установка, повторная установка без потери первой копии, возврат, автоматический откат после искусственной ошибки, отказ при повреждённом пакете и неизвестной версии JS. Конфигурации пользователя остаются неизменными. Контрольные суммы экранных ресурсов сверены с рабочими файлами Pad. Веб-Fluidd на рабочем Pad имеет дополнительные изменения и не совпадает с исходным архивом V2: этот вариант не включён в список совместимости. Неизвестные веб-ресурсы установщик не заменяет.

В архиве исходников из корневой папки выполните на компьютере с Python:

```sh
python scripts/build_sonic_russian_suite.py
python tests/test_sonic_russian_suite.py
```

Результат появится в `dist/sonic_pad_russian/`. Установщик работает с Python 3.7+, сборка и тесты выполнялись на Python 3.12. Команды тестов не подключаются к оборудованию.

Это неофициальное дополнение. Экранная оболочка и ресурсы Creality принадлежат их правообладателям; Fluidd — отдельный открытый проект. Архив содержит изменённые статические ресурсы совместимой сборки, а не новую прошивку Sonic Pad. Пользовательские секреты и персональные настройки в публикацию не включены.

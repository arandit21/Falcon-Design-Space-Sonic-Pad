# Сборка Windows-пакета

Нужны Windows x64, Python **3.12 x64**, C#-компилятор .NET Framework 4 (`csc.exe`), исходники этого репозитория, базовый архив NO_AUTH_PATCH от 11.10.2026 и Frida **17.24.1**. Компилятор по умолчанию ищется в `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe`.

Скачайте базовый архив из ассетов релиза. Установите Frida в отдельную папку сборки и задайте пути в PowerShell:

```powershell
python -m pip install --target .\build\dependencies frida==17.24.1
$env:FALCON_BUILD_PYTHON = "C:\Python312"
$env:FALCON_BUILD_DEPENDENCIES = (Resolve-Path .\build\dependencies).Path
$env:FALCON_LEGACY_PATCH_ZIP = (Resolve-Path .\Falcon_Design_Space_NO_AUTH_PATCH_20261011.zip).Path
python .\scripts\build_release.py
```

Результат: `dist/FalconSonicPad_Setup.exe`, `dist/payload.zip`, `dist/release.json`. В installer встроены Python и Frida, поэтому на целевой Windows они не устанавливаются отдельно. Системный клиент OpenSSH нужен на целевом компьютере. Служба Pad требует его собственные Python 3.7+ и ffmpeg.

Проверки после сборки:

```powershell
python .\tests\test_install.py
python .\tests\test_startup_support.py
python .\tests\test_public_install.py
```

Проверки не отправляют движения или лазерные команды. В тесте службы сетевые соединения и запуск процессов Pad заменены моделями. Они не заменяют аппаратный тест на чистом устройстве.

Базовый архив нужен только сборщику; пользователь готового установщика скачивает оригинальную FDS и новый полный патч. Личные ключи и калибровки не должны добавляться в `dist/payload` или Git.

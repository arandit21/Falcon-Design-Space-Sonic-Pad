# Патч 1.3.0: Falcon Design Space на русском + Sonic Pad

Полный публичный комплект для подключения **Creality Falcon A1 к Falcon Design Space 1.8.0 через Sonic Pad по локальной сети**. Старые экспериментальные папки, ранее созданный SSH-ключ и отдельное применение старого патча не нужны.

## Включено

- Русский интерфейс, офлайн-материалы и базовый NO_AUTH_PATCH от 11.10.2026.
- Проверенный штатный USB-протокол через SSH, нормальные перемещения с параметрами интерфейса.
- Фото Creality Falcon Camera с Sonic Pad, 2592×1944, в штатном интерфейсе FDS.
- Вкладка Sonic Pad рядом с WIFI/IP и сохранение адреса.
- Установщик с выбором папки, запускатель без консоли после сопряжения, правильная иконка окна.
- Создание индивидуального SSH-ключа и установка зависимости R4 при первоначальной настройке.
- Резервные копии, восстановление файлов и настроек, сохранение существующей калибровки пользователя.

## Как установить

1. Скачайте и установите **Falcon_Design_Space_1.8.0_Original.exe**, затем закройте FDS.
2. Запустите **FalconSonicPad_Setup_1.3.0.exe**. Папка по умолчанию: `C:\Program Files\Falcon Design Space\Sonic Pad`.
3. Выполните предложенную первоначальную настройку: IP Pad, проверка отпечатка SSH и root-пароль. Пароль не сохраняется. Скрипты и совместимая служба будут установлены автоматически.
4. Пользуйтесь ярлыком **Falcon — Sonic Pad**. Камера: выберите **Creality Falcon Camera (Sonic Pad)** и нажмите **Фото**.

Требуются Windows x64 с клиентом OpenSSH и оригинальная FDS 1.8.0; на Pad — root SSH, Python 3.7+, ffmpeg и /etc/rc.common. Полный установщик самой FDS размещён здесь, искать его отдельно не нужно. Подпись исходного файла Creality проверена; байты файла не изменены.

## Файлы релиза

- **FalconSonicPad_Setup_1.3.0.exe** — готовый установщик патча.
- **Falcon_Design_Space_1.8.0_Original.exe** — исходный установщик программы.
- **Falcon_SonicPad_Service_1.3.0.zip** — служба R4, ретранслятор, фотоадаптер и инструкция для ручной установки на Pad.
- **Falcon_Design_Space_FULL_PATCH_1.3.0.zip** — патч, служба и русская инструкция одним архивом; оригинальная FDS скачивается отдельно.
- **Falcon_Design_Space_NO_AUTH_PATCH_20261011.zip** — базовый архив для воспроизведения сборки. Пользователю готового 1.3.0 отдельно не нужен.
- **SHA256SUMS.txt**, **verification.json** — контрольные суммы и результаты проверок.

## Служба Sonic Pad

Пакет публикует отдельную службу R4 с регистрацией автозапуска. Это диагностическая служба; сетевой ретранслятор команд запускается Windows через SSH на время работы FDS и временно освобождает от R4 USB-порт. Нативный транспорт и фотоадаптер сохранены из рабочей версии. Ручные команды установки, проверки и удаления — в [инструкции Sonic Pad](https://github.com/arandit21/Falcon-Design-Space-Sonic-Pad/blob/main/docs/SONIC_PAD.md).

## Статус и ограничения

Выпуск **предварительный**. Реальные подключение, перемещения и фото подтверждены пользователем. Создание ключа, обновление/восстановление, команды первичной настройки и новая регистрация службы проверены изолированными тестами. Полная установка 1.3.0 на отдельной чистой Windows/сброшенном Pad, аппаратная перезагрузка с новой службой и полный цикл гравировки/резки ещё не подтверждены.

Камера получает отдельные фото, непрерывного видео нет. Публичный пакет не содержит персональных SSH-ключей, паролей и индивидуальной калибровки автора. На другой геометрии камеры нужна собственная калибровка; существующие профили сохраняются.

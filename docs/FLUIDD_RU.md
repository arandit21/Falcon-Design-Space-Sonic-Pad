# Fluidd на русском — Sonic Pad 54.20, V2

Для полной русификации экрана и веб-интерфейса используйте [общий комплект Sonic Pad 54.20](SONIC_PAD_RUSSIAN_SUITE.md). Этот отдельный пакет сохранён для установки только одной части.

Готовый пакет **Fluidd_Russian_SonicPad_54.20_v2.tar.gz** для веб-интерфейса Fluidd на **Creality Sonic Pad V1.0.6.54.20**. Целевая сборка: **V1.0.18_fluidd / upstream base 1.24.0**.

[Скачать отдельный релиз](https://github.com/arandit21/Falcon-Design-Space-Sonic-Pad/releases/tag/fluidd-ru-54.20-v2) · [Архив](https://github.com/arandit21/Falcon-Design-Space-Sonic-Pad/releases/download/fluidd-ru-54.20-v2/Fluidd_Russian_SonicPad_54.20_v2.tar.gz)

Этот пакет включает русский язык **в браузерном Fluidd**. Он не переводит встроенную сенсорную оболочку Sonic Pad и не относится к русификации Windows-программы Falcon Design Space. Это отдельное дополнение, устанавливать его для работы Falcon через SSH необязательно.

## Что делает V2

В штатной сборке уже есть файл русского перевода `assets/ru-8fa4abd5.js`. Патч добавляет `{name:"Русский",code:"ru"}` в список доступных языков основного JS-пакета.

V1 использовал отдельное имя `index-cbfa4fba-ru.js` и менял ссылку в index.html. V2 оставляет штатное имя **index-cbfa4fba.js**, возвращает штатный index.html и обновляет revision основного пакета в **sw.js**, чтобы браузерный PWA-кэш обновился. Сам файл русского перевода не заменяется. Это активация встроенного перевода Fluidd, а не новый перевод всех его строк.

Установщик принимает точное штатное состояние целевой сборки и известный V1 alias-патч. Для неизвестных файлов проверка хешей прерывает установку. Для других прошивок и сборок Fluidd совместимость не подтверждена.

## Установка

Перед началом завершите текущую печать/задание. Скачайте архив и откройте PowerShell в папке с ним. Укажите адрес своего Pad:

```powershell
$PadAddress = "192.168.1.36"
$SshCompat = @("-oHostKeyAlgorithms=+ssh-rsa", "-oPubkeyAcceptedAlgorithms=ssh-rsa", "-oMACs=+hmac-sha1")
scp -O @SshCompat .\Fluidd_Russian_SonicPad_54.20_v2.tar.gz "root@${PadAddress}:/mnt/UDISK/"
ssh @SshCompat "root@$PadAddress"
```

Проверьте отпечаток своего устройства и введите его root-пароль в запросе SSH. Следующие команды выполняются **на Sonic Pad**:

```sh
cd /mnt/UDISK
sha256sum Fluidd_Russian_SonicPad_54.20_v2.tar.gz
tar -xzf Fluidd_Russian_SonicPad_54.20_v2.tar.gz
cd Fluidd_Russian_SonicPad_54.20_v2
chmod +x verify.sh install.sh restore.sh
./verify.sh
```

SHA-256 исходного архива:

```text
ca23b0afe62dcbf627df21b9c74f6e729a1736c16b1c992b4466ed804392d681
```

Продолжайте, если проверка распознала штатную сборку (`STOCK ... READY FOR V2`) или известный V1 (`V1 ALIAS PATCH INSTALLED - READY FOR V2`):

```sh
./install.sh
./verify.sh
```

Ожидаемый итог:

```text
STATUS: FLUIDD RUSSIAN V2 INSTALLED
```

Если V2 уже установлен, повторная установка не требуется. При `HASH MISMATCH`, `UNKNOWN / MIXED FILE SET` или `MISSING` остановитесь: пакет не следует применять к другой сборке принудительно.

## После установки

Полностью закройте вкладку Fluidd и откройте её снова. При необходимости выполните **Ctrl+Shift+R**, затем выберите **Русский** в настройках языка Fluidd. Если Moonraker уже хранит `uiSettings.general.locale=ru`, сбрасывать это значение не нужно. Прошивка Pad, Klipper и конфигурация принтера не заменяются.

## Резервная копия и возврат

Предыдущее состояние сохраняется в `/mnt/UDISK/fluidd-russian-v2-preinstall-backup-54.20`. При неудачной финальной проверке установщик пытается восстановить эти файлы.

Для возврата к **полностью штатным файлам Fluidd**, поставляемым в этом пакете:

```sh
cd /mnt/UDISK/Fluidd_Russian_SonicPad_54.20_v2
./restore.sh
```

Это возврат к штатной сборке, а не восстановление V1. После него в настройках Fluidd выберите English/Browser default, если ранее был сохранён русский язык, и обновите вкладку. Не удаляйте папку пакета, пока нужен restore.sh и находящиеся в ней штатные файлы.

## Проверка перед публикацией

Архив опубликован без изменения байтов. Проверены его структура, отсутствие ссылок и выходов за каталоги, все семь хешей файлов из внутренних манифестов, неизменность index.html относительно штатной копии и точное добавление только русского пункта в основной JS-пакет. Установка на реальный Pad в ходе этой публикации не выполнялась.

Исходный README внутри архива записан в Windows-1251; если он отображается нечитаемо, используйте эту UTF-8-инструкцию. Пути в stock.sha256 и patched.sha256 относятся к каталогу первоначальной сборки `/mnt/data`; на Pad для проверки установленного состояния предназначен **verify.sh**.

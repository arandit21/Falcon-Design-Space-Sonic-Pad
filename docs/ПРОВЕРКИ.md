# Проверки и границы подтверждённой работы

На реальной рабочей установке пользователь подтвердил подключение Falcon A1 через Sonic Pad, нормальные перемещения, получение снимка камеры 2592×1944, вкладку Sonic Pad, русский интерфейс и иконку окна. Восстановление собственной калибровки также проверено на этой установке.

Для публичного пакета отдельно проверяются создание ключа без прежней установки, сохранение настроек, резервное копирование и восстановление файлов, команды SSH-сопряжения, установка службы в изолированной файловой модели, отказ при неизвестной службе, синтаксис Python 3.7 для Pad, целостность пакетов и отсутствие персональных ключей/калибровки. Результаты — в verification.json релиза.

Пока не подтверждены полная первая установка публичного 1.3.0 на отдельной чистой Windows, установка и перезагрузка на сброшенном Sonic Pad, новый аппаратный сеанс сопряжения этим установщиком и полный цикл гравировки/резки. Поэтому выпуск предварительный.

Нативный USB-транспорт и фотоадаптер сохранены из рабочей версии. Новая обвязка службы проверяется отдельно без движений и включения лазера. Скриншоты от 23 октября 2026 года показывают рабочую установку автора. Её отметка «Откалибровано» не является универсальной калибровкой других станков.

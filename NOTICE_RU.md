# Сторонние компоненты

Это неофициальный проект пользователя arandit21, не официальный выпуск Creality.

Исходный установщик Falcon Design Space 1.8.0, базовый изменённый EXE, перевод, значок Falcon и база материалов распространяются отдельно как компоненты Creality/исходного патча. Их права не переоформляются лицензией репозитория. Байты оригинального установщика не изменяются; SHA-256 указан в SHA256SUMS.txt релиза.

Windows-пакет содержит Python 3.12 со штатным LICENSE.txt и Frida 17.24.1. У сторонних компонентов собственные условия. Тексты из поставляемых пакетов сохранены в third-party: Python LICENSE.txt и Frida COPYING (wxWindows Library Licence, Version 3.1). Проекты: https://www.python.org/ и https://frida.re/ . OpenSSH используется из Windows. Python и ffmpeg на Sonic Pad должны присутствовать в его системе; служба не скачивает их автоматически.

Пароли, приватные ключи, фотографии мастерской, журналы устройства и персональный профиль калибровки не публикуются. Скриншоты интерфейса предоставлены автором проекта.
